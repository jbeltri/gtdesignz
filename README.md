# GTDESIGNS

Prototype website for G T Designz Limited, an architectural design and technical services practice.

## Pages

- `index.html`: landing page, services, portfolio slider, interactive project map, FAQs and enquiry form.
- `case-studies.html`: structured project knowledge for prospective clients and search/answer engines.

## Local preview

```powershell
python -m http.server 4173
```

Open `http://localhost:4173`.

## Deployment

The site is designed for GitHub Pages and uses relative asset paths.
